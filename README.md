# 📸 React Image Gallery

A modern and responsive Image Gallery built using React.js.

## 🚀 Features

- Responsive Design
- Category Filters
- Lightbox Popup
- Previous / Next Navigation
- Hover Animation
- Image Overlay
- Mobile Friendly
- React Hooks
- CSS Grid Layout

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- React Icons

## 📂 Project Structure

```text
src
│
├── assets
├── components
│   ├── Gallery.js
│   └── Gallery.css
├── data
│   └── images.js
├── App.js
└── App.css
```

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/react-image-gallery.git
```

Go to project

```bash
cd react-image-gallery
```

Install dependencies

```bash
npm install
```

Run project

```bash
npm start
```

Open

```text
http://localhost:3000
```
